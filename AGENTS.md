# Scope of this research repository

The goal is the full original topological Poincare proposition, not a weaker
metric-sign or certificate-dependent statement. Never mark the target proved
or submission-ready because a component builds or a library is imported.

Read STATUS.md and the component's own README before changing it. Preserve
the immutable proof/evidence snapshots and their source hashes. Put new work
in a new version or component. Keep dependencies, code ownership and existing
local modifications intact. Never publish build caches, credentials or
private information. Retain third-party licenses and attribution.

Formal changes require actual Lean checking and a transitive axiom audit;
full replay uses the pinned checker and an honest record of its limitations.
The complete theorem needs its own exact statement and proof check, not a
JSON boolean set to true or a new unproved assumption.

Award PR #438 is not an eligible application until the full problem is
proved. Follow the live official CONTRIBUTING and PR template: external
source references only, exact branch and SHA, and allowed catalog changes.
Do not submit intermediate results to the prize repository or silently
change a historical record to pretend that new code was already verified.
